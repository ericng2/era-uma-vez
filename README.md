# Era Uma Vez Você

Livro infantil personalizado. O comprador conta o nome da criança, a idade e o que
ela está vivendo; a história é escrita e ilustrada em cima disso e entregue em PDF.

- `index.html` — a vitrine
- `livros/` — três amostras: Manu (medo de dormir), Téo (primeiro dia de aula),
  Cecília (aniversário)

⚠️ Nenhuma foto de criança é usada nas amostras. A foto é opcional no produto e
nunca é requisito de compra.
